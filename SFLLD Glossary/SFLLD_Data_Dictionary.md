# Freddie Mac SFLLD Data Dictionary & Modeling Reference

## 1. Origination Data File Layout (`historical_data_<YEAR>Q<#>.txt`)

|   Pos | Field Name             | Type   | Description & Valid Values                                                              | Modeling Utility                                                                               |
|------:|:-----------------------|:-------|:----------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------|
|     1 | CREDIT_SCORE           | Num    | Credit score of the borrower at origination (301–850). 9999 = Not Available.            | Baseline PD driver. Monotonic negative constraint (-1). Impute 9999 to median or bin.          |
|     2 | FIRST_PAYMENT_DATE     | Date   | First scheduled monthly payment date (YYYYMM).                                          | Establishes baseline amortization schedule and origination seasonality.                        |
|     3 | FIRST_TIME_HOMEBUYER   | Char   | Y = Yes, N = No, 9 = Unknown.                                                           | Auxiliary borrower capacity / seasoning indicator.                                             |
|     4 | MATURITY_DATE          | Date   | Scheduled maturity date of the mortgage (YYYYMM).                                       | Used with First Payment Date to derive original loan term.                                     |
|     5 | METROPOLITAN_DIVISION  | Num    | Metropolitan Statistical Area (MSA) or Division code (5 digits). Blank = Non-metro.     | Primary join key for FHFA MSA-level Purchase-Only HPI indices.                                 |
|     6 | MORTGAGE_INSURANCE_PCT | Num    | Percentage of initial balance covered by primary MI (0–55%). 000 = None, 999 = Unknown. | Key recovery credit enhancement in High-LTV (HQA) reference pools.                             |
|     7 | NUMBER_OF_UNITS        | Num    | Number of residential units securing the mortgage (1–4). 99 = Unknown.                  | 2-4 unit properties historically carry higher default and loss severity rates.                 |
|     8 | OCCUPANCY_STATUS       | Char   | P = Primary, S = Second Home, I = Investment, 9 = Unknown.                              | Risk weight differentiator; investment properties exhibit elevated default rates under stress. |
|     9 | ORIGINAL_CLTV          | Num    | Original Combined Loan-to-Value including subordinate liens (6–200%). 999 = Unknown.    | Total borrower leverage metric; captures true initial skin-in-the-game.                        |
|    10 | ORIGINAL_DTI           | Num    | Debt-to-Income ratio (0–65%). 999 = Unknown.                                            | Debt service capacity; enforce monotonic positive constraint (+1).                             |
|    11 | ORIGINAL_UPB           | Num    | Original Unpaid Principal Balance in whole dollars.                                     | Base denominator for dynamic equity calculation: Value_0 = UPB_0 / (LTV_0 / 100).              |
|    12 | ORIGINAL_LTV           | Num    | Original first-lien Loan-to-Value (6–105%). 999 = Unknown.                              | Core underwriting baseline. Enforce monotonic positive constraint (+1).                        |
|    13 | ORIGINAL_INTEREST_RATE | Num    | Original note rate percentage (e.g., 4.250).                                            | Determines refinance incentive spread (Orig Rate - Prevailing Rate) and prepayment drag.       |
|    14 | CHANNEL                | Char   | R = Retail, B = Broker, C = Correspondent, T = Third-Party, 9 = Unknown.                | Originator channel quality control and performance dispersion tracking.                        |
|    15 | PPM_FLAG               | Char   | Prepayment Penalty Mortgage flag: Y = Yes, N = No.                                      | Nearly 100% 'N' in post-QM conventional conforming paper.                                      |
|    16 | AMORTIZATION_TYPE      | Char   | FRM = Fixed-Rate Mortgage.                                                              | Ensures standard fixed-payment amortization curves across all cohorts.                         |
|    17 | PROPERTY_STATE         | Char   | Two-letter state postal abbreviation (e.g., VA, CA, FL).                                | Primary join key for BLS State Unemployment series and judicial foreclosure regimes.           |
|    18 | PROPERTY_TYPE          | Char   | SF = Single-Family, CO = Condo, CP = Co-op, MH = Manufactured, PU = PUD, 99 = Unknown.  | Collateral liquidity indicator; condos and manufactured housing show higher severity.          |
|    19 | POSTAL_CODE            | Num    | First 3 digits of property ZIP code. 000 = Unknown / masked.                            | Sub-state geographic grouping for regional macro shock attribution.                            |
|    20 | LOAN_SEQUENCE_NUMBER   | Char   | Unique loan identifier (e.g., F115Q1000001).                                            | Primary alphanumeric joining key across Origination and Performance records.                   |
|    21 | LOAN_PURPOSE           | Char   | P = Purchase, C = Cash-Out Refi, R = No Cash-Out Refi, U = Undisclosed, 9 = Unknown.    | Cash-out refi cohorts demonstrate heightened sensitivity during housing market drawdowns.      |
|    22 | ORIGINAL_LOAN_TERM     | Num    | Scheduled amortization term in months (e.g., 360, 180).                                 | Used to compute scheduled monthly paydown factor and remaining maturity.                       |
|    23 | NUMBER_OF_BORROWERS    | Num    | Number of obligated borrowers (1–2+). 99 = Unknown.                                     | Co-borrower income diversification reduces idiosyncratic default rates.                        |
|    24 | SELLER_NAME            | Char   | Originating seller institution name (or 'Other').                                       | Counterparty underwriting variance and quality assessment.                                     |
|    25 | SERVICER_NAME          | Char   | Servicing institution name (or 'Other').                                                | Servicer workout efficiency controls foreclosure timelines and curing rates.                   |
|    26 | SUPER_CONFORMING_FLAG  | Char   | Y = High-cost area jumbo-conforming loan, Blank/N = Standard limit.                     | Stratification flag for high-balance collateral behavior.                                      |

## 2. Monthly Performance Data File Layout (`historical_data_time_<YEAR>Q<#>.txt`)

|   Pos | Field Name                      | Type     | Description & Valid Values                                                                             | Modeling Utility                                                                                 |
|------:|:--------------------------------|:---------|:-------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------|
|     1 | LOAN_SEQUENCE_NUMBER            | Char     | Unique loan identifier.                                                                                | Joining key linking monthly performance records back to origination attributes.                  |
|     2 | MONTHLY_REPORTING_PERIOD        | Date     | Monthly performance cycle accounting date (YYYYMM).                                                    | Time coordinate t for snapshot observation and forward-window indexing.                          |
|     3 | CURRENT_ACTUAL_UPB              | Num      | Active unpaid principal balance in dollars. 0.00 if liquidated or paid off.                            | Core EAD (Exposure at Default) and portfolio balance weighting metric.                           |
|     4 | CURRENT_LOAN_DELINQUENCY_STATUS | Char/Num | 0 = Current, 1 = 30-59 DPD, 2 = 60-89 DPD, 3 = 90-119 DPD ... RA = REO Acquisition.                    | Primary classification label: status >= 3 or RA triggers default target (y = 1).                 |
|     5 | LOAN_AGE                        | Num      | Number of scheduled payments elapsed since origination.                                                | Seasoning metric; default hazard functions typically peak between months 24 and 60.              |
|     6 | REMAINING_MONTHS_TO_MATURITY    | Num      | Scheduled months remaining until full amortization.                                                    | Forward cash-flow projections and scheduled principal decay calculations.                        |
|     7 | DEFECT_SETTLEMENT_DATE          | Date     | Date loan was repurchased or resolved for underwriting defects (YYYYMM).                               | Isolates operational/repurchase removals from true credit defaults.                              |
|     8 | MODIFICATION_FLAG               | Char     | Y = Modified loan terms, N = Standard original terms.                                                  | Indicator of prior distress; modified cohorts exhibit elevated re-default curves.                |
|     9 | ZERO_BALANCE_CODE               | Char     | 01 = Prepaid/Refi, 02 = Third-Party Sale, 03 = Short Sale, 06 = Repurchase, 09 = REO, 15 = Charge-off. | Target divider: 01 = voluntary prepayment (y=0); 02, 03, 09, 15 = credit defaults (y=1).         |
|    10 | ZERO_BALANCE_EFFECTIVE_DATE     | Date     | Date zero balance disposition was recorded (YYYYMM).                                                   | Pinpoints exact liquidation / payoff timing for survival models.                                 |
|    11 | CURRENT_INTEREST_RATE           | Num      | Active note rate accounting for modifications or step resets.                                          | Servicer interest advance carrying cost calculation.                                             |
|    12 | CURRENT_DEFERRED_UPB            | Num      | Non-interest-bearing principal deferred under modification agreements.                                 | Must be added to Current Actual UPB to evaluate total credit exposure at default.                |
|    13 | DDLPI                           | Date     | Due Date of Last Paid Installment (YYYYMM).                                                            | Measures total months of borrower non-payment prior to resolution.                               |
|    14 | MI_RECOVERIES                   | Num      | Primary mortgage insurance proceeds received upon liquidation.                                         | Direct loss-mitigating cash inflow for High-LTV severity modeling.                               |
|    15 | NET_SALES_PROCEEDS              | Num/Char | Net cash received from property disposition after brokerage fees. U = Unknown.                         | Primary numerator in empirical recovery rate calibration: Recovery = Net Proceeds / Default UPB. |
|    16 | NON_MI_RECOVERIES               | Num      | Secondary or third-party recoveries received.                                                          | Additional recovery cash flow offsetting gross liquidation losses.                               |
|    17 | EXPENSES                        | Num      | Cumulative property preservation and inspection out-of-pocket servicer costs.                          | Liquidation cost add-on expanding realized loss severity.                                        |
|    18 | LEGAL_COSTS                     | Num      | Cumulative attorney, foreclosure filing, and bankruptcy legal costs.                                   | Foreclosure friction parameter; substantially higher in judicial foreclosure states.             |
|    19 | MAINTENANCE_COSTS               | Num      | Costs to maintain and repair REO property prior to sale.                                               | Direct physical carrying friction.                                                               |
|    20 | TAXES_AND_INSURANCE             | Num      | Escrow advances for hazard/flood insurance and property taxes paid by servicer.                        | Timeline carrying cost; scales linearly with months in default.                                  |
|    21 | MISC_EXPENSES                   | Num      | Other liquidation-related ancillary expenses.                                                          | Liquidation expense reconciliation.                                                              |
|    22 | ACTUAL_LOSS                     | Num      | Total realized dollar loss (or gain) allocated to the loan upon termination.                           | Ground-truth benchmark for empirical LGD: LGD = ACTUAL_LOSS / Removal_UPB.                       |
|    23 | MOD_COST                        | Num      | Cumulative economic cost of concessions granted under modifications.                                   | Impairment accounting for CRT tranche loss allocation.                                           |
|    24 | STEP_MOD_FLAG                   | Char     | Y = Loan on interest rate step-up schedule, N = Fixed modified rate.                                   | Tracks future payment shock risk when below-market teaser rates adjust.                          |
|    25 | DEFERRED_PAYMENT_PLAN           | Char     | Y = Completed payment deferral workout, N = Standard resolution.                                       | Crucial for post-2020 COVID forbearance tracking.                                                |
|    26 | ELTV                            | Num      | Estimated Loan-to-Value calculated by internal proprietary models (0–999%).                            | Freddie Mac benchmark to validate synthetic MTMLTV calculations.                                 |
|    27 | ZERO_BALANCE_REMOVAL_UPB        | Num      | Actual UPB at the moment the loan was removed from the reference pool.                                 | Definitive denominator for empirical loss severity calculation.                                  |
|    28 | DELINQUENT_ACCRUED_INTEREST     | Num      | Unpaid interest accrued from default through final liquidation disposition.                            | Gross loss component in STACR/ACIS credit enhancement write-downs.                               |
